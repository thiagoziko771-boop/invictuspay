🚀 PASSO 1: CONFIGURAR NETLIFY (2-3 minutos)
─────────────────────────────────────────────

1. Abra: https://app.netlify.com
2. Selecione seu site
3. Vá em: Settings → Build & Deploy → Environment
4. Clique: "Add environment variable"
5. Configure:
   
   PINGUPAG_API_KEY
   │
   └→ 5a4a884661598e034154315cc12ce8e55ebfd026625c057dcf673b7ca7512384

6. Clique: "Save"
7. Redeploy manual: Settings → Deploys → Deploy site
   └→ Aguarde finalizar (esperar ~1 min)

✓ Completo!

═══════════════════════════════════════════════════════════════════

🔔 PASSO 2: CONFIGURAR WEBHOOK PINGUPAG (2-3 minutos)
────────────────────────────────────────────────────

1. Abra: https://app.pingupag.com
2. Login com suas credenciais
3. Vá em: Configurações e API → Webhooks
4. Clique: "Adicionar Webhook"
5. Configure:

   Nome: AVENPAY Webhook
   URL:  https://seu-site.netlify.app/.netlify/functions/webhook-pingupag
   
   (Substitua "seu-site" pelo nome real do seu site)

6. Selecione eventos:
   ✓ Transação Criada
   ✓ Transação Aprovada
   ✓ Transação Recusada
   ✓ Transação Refundada

7. Clique: "Enviar Teste"
   └→ Resultado esperado: {"success": true, "message": "..."}

✓ Completo!

═══════════════════════════════════════════════════════════════════

📤 PASSO 3: DEPLOY (1-2 minutos)
────────────────────────────────

Execute estes comandos no terminal:

git add functions/pix-pingupag.js \
        functions/check-payment-pingupag.js \
        functions/webhook-pingupag.js \
        .env.example \
        PINGUPAG_*.md \
        test-pingupag.js

git commit -m "🔌 feat: integrate Pingupag gateway

- Add pix-pingupag.js for PIX generation
- Add check-payment-pingupag.js for status check
- Add webhook-pingupag.js for payment notifications
- Includes comprehensive documentation"

git push origin main

✓ Netlify fará deploy automático
✓ Aguarde ~1-2 minutos

🚨 TROUBLESHOOTING RÁPIDO

Problema: "PINGUPAG_API_KEY não configurada"
Solução: Redeploy no Netlify após adicionar variável

Problema: "Webhook não está sendo disparado"
Solução: Teste URL no painel Pingupag ("Enviar Teste")

Problema: "Erro 502 ao gerar PIX"
Solução: Verifique logs Netlify (Functions → Logs)
